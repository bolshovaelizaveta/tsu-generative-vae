# Генеративные технологии для задач компьютерного зрения

Данный репозиторий содержит работы, выполненные в рамках магистерской программы **«Компьютерное зрение и нейронные сети»** в Томском государственном университете (ТГУ).

**Студентка:** Большова Елизавета Александровна  


## О проекте
Целью данного курса является изучение и практическая реализация современных генеративных архитектур: от классических вариационных автоэнкодеров (VAE) до современных диффузионных моделей. Основной упор сделан на анализ латентного пространства, качество генерации и интерпретируемость результатов.

## Выполненные работы

| Задание | Технологии | Отчет |
| :--- | :--- | :--- | 
| **№1. Вариационный автоэнкодер (VAE)** | PyTorch, VAE, Fashion-MNIST, Latent Space Interpolation | [HW_1_REPORT.md](./HW_1_REPORT.md) |
| **№2. Сравнение VAE и диффузионных моделей** | VAE, Diffusion Models (DDPM/Stable Diffusion), Image Metrics | [HW_2_REPORT.md](./HW_2_REPORT.md) |


## Структура репозитория

*   `VAE_Implementation.ipynb` — Основной ноутбук с реализацией архитектуры VAE, циклом обучения и блоком визуализации.
*   `results/` — Визуализации: коллажи генерации, графики обучения и примеры интерполяции.
*   `HW_1_REPORT.md` — Подробный отчет по первой работе с анализом латентного пространства.
