# Генеративные технологии для задач компьютерного зрения

Данный репозиторий содержит работы, выполненные в рамках магистерской программы **«Компьютерное зрение и нейронные сети»** в Томском государственном университете (ТГУ).

**Студентка:** Большова Елизавета Александровна  


## О проекте
Целью данного курса является изучение и практическая реализация современных генеративных архитектур: от классических вариационных автоэнкодеров (VAE) до современных диффузионных моделей. Основной упор сделан на анализ латентного пространства, качество генерации и интерпретируемость результатов.

## Ключевые результаты итогового проекта
В ходе исследования было проведено сравнение моделей на датасете **Fashion-MNIST**. Основные метрики качества оценивались с помощью независимого классификатора с точностью 93.56%.

**Итоговые показатели качества:**
*   **VAE:** Средняя уверенность классификатора — **0.7333**
*   **DDPM:** Средняя уверенность классификатора — **0.7932**

Экспериментально подтверждено, что диффузионный подход (DDPM) обеспечивает на **10.5%** больше качественных сэмплов по сравнению с VAE за счет лучшего восстановления высокочастотных признаков и топологии объектов.
